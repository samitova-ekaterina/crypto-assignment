## Step 1: Identifying the Correct Symmetric Key

**Task:** Given three 128-bit keys in hexadecimal format and a SHA-256 hash of the correct key, determine which key corresponds to the given hash.

**Solution:**

According to the deterministic property of hash functions, identical input data always produces the same hash. Therefore, to identify the correct key, it is sufficient to compute the SHA-256 hash of each of the three candidates and compare the result with the target value.

**Algorithm:**
1. Convert the HEX representation of the key to a byte array
2. Compute the SHA-256 hash of the resulting array
3. Compare the result with the target hash

**Implementation:**
```java
for (String hexKey : candidateKeys) {
    byte[] keyBytes = hexToBytes(hexKey);
    byte[] hashBytes = sha256(keyBytes);
    String hashHex = bytesToHex(hashBytes);
    
    if (hashHex.equals(targetHash)) {
        correctKey = hexKey;
    }
}
```

**Result:** Key `54684020247570407220244063724074` produces a hash matching the target value.

## Step 2: Decrypting the Message

**Task:** Using the identified symmetric key, decrypt the message encrypted with AES-128 in CBC mode.

**Input Data:**
- Ciphertext: `876b4e970c3516f333bcf5f16d546a87aaeea5588ead29d213557efc1903997e`
- Initialization Vector (IV): `656e6372797074696f6e496e74566563`
- Key: `54684020247570407220244063724074`

**Solution:**

AES is a symmetric block cipher where the same key is used for both encryption and decryption. CBC mode requires an initialization vector to process the first block. For correct decryption, the standard PKCS5Padding scheme is applied.

**Algorithm:**
1. Convert the key, ciphertext, and IV from HEX to bytes
2. Initialize the AES cipher in decryption mode with CBC and PKCS5Padding parameters
3. Perform decryption
4. Convert the result to a UTF-8 string

**Implementation:**
```java
SecretKeySpec keySpec = new SecretKeySpec(keyBytes, "AES");
IvParameterSpec ivSpec = new IvParameterSpec(ivBytes);

Cipher cipher = Cipher.getInstance("AES/CBC/PKCS5Padding");
cipher.init(Cipher.DECRYPT_MODE, keySpec, ivSpec);

byte[] plainBytes = cipher.doFinal(cipherBytes);
String plainText = new String(plainBytes, StandardCharsets.UTF_8);
```

**Result:** `Hello Blockchain!`

## Step 3: Generating an Asymmetric Key Pair

**Task:** Generate a key pair using Elliptic Curve Cryptography (ECC).

**Solution:**

Elliptic Curve Cryptography provides a high level of security with relatively short key lengths. The EC algorithm with a 256-bit key length is used for generation.

**Algorithm:**
1. Create a key pair generator for the EC algorithm
2. Initialize the generator with a 256-bit key length parameter
3. Generate the key pair
4. Encode the public key in Base64 format

**Implementation:**
```java
KeyPairGenerator keyPairGenerator = KeyPairGenerator.getInstance("EC");
keyPairGenerator.initialize(256);
KeyPair keyPair = keyPairGenerator.generateKeyPair();

String publicKeyBase64 = Base64.getEncoder().encodeToString(
    keyPair.getPublic().getEncoded()
);
```

## Step 4: Creating a Digital Signature

**Task:** Create a digital signature of the decrypted message using the generated private key.

**Solution:**

The ECDSA algorithm combined with the SHA-256 hash function is used to create the signature. This approach ensures authenticity, integrity, and non-repudiation of the signed message.

**Algorithm:**
1. Initialize the signature object with the SHA256withECDSA algorithm
2. Load the private key
3. Pass the message data
4. Generate the signature and encode it in Base64

**Implementation:**
```java
Signature signature = Signature.getInstance("SHA256withECDSA");
signature.initSign(keyPair.getPrivate());
signature.update(message.getBytes(StandardCharsets.UTF_8));
byte[] signatureBytes = signature.sign();

String signatureBase64 = Base64.getEncoder().encodeToString(signatureBytes);
```
